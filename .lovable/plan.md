# Premium portfolio website

## What I’ll build
- A polished four-page portfolio: Home, About, Work, and Resources.
- A shared minimal header and cinematic gradient footer with a Nairobi location marker.
- A bold Home introduction plus paired Mission and Vision cards.
- A concise About page centered on zero-to-one growth, brand architecture, and institutional partnerships.
- A Work page presenting physical and digital infrastructure, ending with the emerald-to-black partnership banner.
- A stark black Resources page offering downloadable operational templates.

## Visual direction
- Pristine white and soft off-white surfaces with generous whitespace.
- Editorial serif headlines paired with a precise modern sans-serif body.
- Vibrant orange accents, delicate borders, soft corners, and pill-shaped actions.
- Restrained motion and strong typographic hierarchy inspired by premium editorial portfolios.

## Technical details
- Use the existing site framework and shared navigation patterns.
- Define the full palette, typography, radii, gradients, and motion as reusable design tokens.
- Add unique search and social metadata to every page.
- Keep all navigation and download/partnership actions functional and keyboard accessible.
- Verify the finished pages at desktop and mobile widths, including overflow and console errors.
